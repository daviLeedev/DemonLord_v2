# 전투 대응 모의전 프로토타입

## 한 문장

> 공유 SP 안에서 각 아군의 기술을 고르면, 기술마다 다른 행동 속도로 아군과 적의 여섯 행동이 한 줄에 다시 정렬되고, 앞 행동이 만든 상태를 이용해 다음 행동을 설계하는 2D 자동 전투다.

카드 덱, 타이밍 바, 충돌·합, 코인, 정신력, 흐트러짐, 별도 방어 페이즈는 사용하지 않는다.

## 이번 구현의 7단계

1. **집행관 진입** — `combat-liaison-officer`의 대화를 마지막까지 진행하면 모의전이 열린다. 대화를 닫으면 열리지 않는다.
2. **전장 파악** — 화면 전체를 채우는 2D 전투 배경 위에 좌측의 작은 아군 부대 목록과 투명 오버레이를 올린다. 적의 공개 행동은 적 이름과 붉은 포물선 화살로 실제 목표까지 보인다.
3. **아군 선택** — 좌측의 작은 세로 목록에서 슬라임·해골·고블린 중 한 명을 고른다. 선택한 부대는 초록 테두리로 강조된다.
4. **기술과 표적 선택** — 선택한 인물의 고정 기술 두 개가 **목록 바로 옆**에 표시된다. 적을 누르면 파란 포물선 표적선이 생기고, 기술을 누르면 그 인물의 예약 행동이 갱신된다.
5. **속도 행동선 설계** — 아군 세 행동과 적 세 의도를 합친 여섯 칸을 `행동 속도` 높은 순서로 즉시 다시 정렬한다. 속도는 `행동자 기본 속도 + 선택한 기술(또는 적 의도)의 속도 보정 + 상태 보정`이다. 수동으로 순서를 밀거나 당기지 않는다.
6. **자동 재생** — 실행을 누르면 행동선의 1번부터 6번까지 한 칸씩 재생된다. 아군과 적은 속도 순서에 따라 자연스럽게 섞인다. 한 행동의 HP·상태·SP가 바로 다음 행동에 반영되고, 죽은 행동자나 대상의 칸은 어둡게 표시되어 `취소`된다. 다른 대상으로 몰래 바꾸지 않는다.
7. **결과와 복귀** — 여섯 행동이 끝나면 SP를 회복하고 다음 라운드를 계획한다. 적 전멸/아군 전멸 시 결과 화면에서 다시 모의하거나 집행관 앞으로 복귀한다.

## 가져온 구조

### 브라운더스트2에서 가져온 것

- 파티 전체가 공유하는 SP
- 캐릭터별 고정 스킬 세트
- 작은 부대 목록에서 캐릭터를 고른 뒤, 해당 인물의 스킬만 바로 옆에 보여 주는 조작
- 실행 전에 모든 아군 기술을 선택하고 결과 행동선을 설계하는 감각
- 앞 행동의 버프·디버프·SP 변화가 뒤 행동을 강화하는 연쇄
- 계획을 확정한 뒤 자동으로 보는 전투 재생

### 림버스 컴퍼니에서 가져온 것

- 좌측 아군·우측 적의 전장 구도
- 적의 행동과 목표를 전투 전에 공개하는 의도 표시
- 적 의도를 실제 표적까지 잇는 붉은 곡선 화살
- 현재 선택한 아군 공격을 표시하는 파란 곡선 표적선
- 행동 속도에 의해 양측 행동이 한 행동선에 섞이는 전투 흐름
- 한 행동이 끝날 때마다 상태가 바뀌는 가시적인 행동선
- 기본 효과는 확정, 그 위에 단 한 번의 보너스 확률 판정

### 의도적으로 뺀 것

- 충돌/합과 적 행동 상쇄
- 코인, 정신력, 죄악 공명
- 카드·덱·드로우
- 흐트러짐/브레이크 게이지
- 타이밍 바·패링·순발력 입력
- 공격과 방어의 분리 단계, 세무관 전투 스킬

## 화면 계약

```text
┌──────────────────── 투명 상단 오버레이: 라운드 / 공유 SP / 단계 / 나가기 ────────────────────┐
│                                                                                              │
│  ┌ 좌측: 작은 아군 목록 ┐ ┌ 바로 옆: 선택 캐릭터 기술 2개 ┐      전 화면 2D 전투 배경          │
│  │ ① 슬라임 HP / 배정   │ │ 이름 / SP / 확정 효과          │      아군            적            │
│  │ ② 해골   HP / 배정   │ │ 보너스 확률 / 보너스 효과      │        ──파란 곡선──▶              │
│  │ ③ 고블린 HP / 배정   │ └─────────────────────────────────┘        ◀─붉은 곡선──               │
│  └──────────────────────┘      (모두 작고 투명한 오버레이)                                  │
│                                                                                              │
│  ───────────────── 투명 하단 행동선: [SPD 52 슬라임] → [SPD 40 검사] → … ─────────────────  │
└──────────────────────────────────────────────────────────────────────────────────────────────┘
```

`1920×1080` 기준에서 좌측 목록과 스킬의 결합 폭은 `442px`(약 23%)까지만 쓴다. 목록 행은 `180×58`, 기술 행은 `224×62`이며, 기술 정보는 최대 두 줄로 요약한다. 상단 헤더·좌측 목록/기술·하단 행동선은 모두 작고 투명한 오버레이로 두어, 큰 어두운 중앙 스테이지 패널을 만들지 않고 배경 일러스트가 먼저 읽히게 한다.

`combat_training_backdrop_v1.png`은 이번 프로토타입의 화면 전체를 채우는 2D 전투 배경 에셋이다. 캐릭터 카드처럼 큰 직사각형을 전장에 놓지 않고, 아군·적 표현과 의도/표적 화살표는 이 배경 위에 가볍게 얹는 오버레이로 구성한다.

## 공유 SP, 속도, 행동 연쇄

- 시작 SP: `4`
- 최대 SP: `8`
- 라운드 종료 회복: `2`
- 모든 아군은 라운드당 한 기술씩 고른다. 같은 캐릭터의 다른 기술을 누르면 그 캐릭터의 예약이 교체되고 행동선도 즉시 다시 정렬된다.
- 계획의 어느 행동 시점에서도 SP가 부족하면 실행할 수 없다.

현재 예시 속도는 아래와 같다. 같은 슬라임이라도 `미끄러운 바닥`은 가장 먼저 들어가지만 `탄성 돌진`은 뒤로 밀린다.

| 행동 | 행동 속도 |
|---|---:|
| 슬라임 — 미끄러운 바닥 | 52 |
| 견습 검사 — 공개 돌진 | 40 |
| 고블린 — 돌팔매 견제 | 36 |
| 해골 — 성문 지연전 | 35 |
| 해골 — 뼈창 찌르기 | 30 |
| 슬라임 — 탄성 돌진 | 28 |
| 견습 방패병 — 공개 압박 | 26 |
| 고블린 — 엄폐 기습 | 25 |
| 견습 마법사 — 공개 영창 | 20 |

각 기술은 두 겹이다.

1. **확정 패키지**: SP 변화, 기본 피해, 점착/노출/표식/억제 같은 상태가 반드시 적용된다.
2. **보너스 1회**: 계산된 확률로 한 번만 판정한다. 성공하면 보너스 피해와 보너스 억제가 더해진다.

명중·회피·치명타를 다시 굴리지 않는다. 보너스가 실패해도 기본 행동은 취소되지 않는다. 확률은 `5~95%` 범위로 제한한다.

| 아군 | 기술 | 핵심 연쇄 |
|---|---|---|
| 슬라임 001호 | 미끄러운 바닥 / 탄성 돌진 | 점착과 SP 회복 → 다음 돌진 보너스 강화 |
| 해골 경비조 | 성문 지연전 / 뼈창 찌르기 | 억제로 공개 적 피해 감소, 노출로 기습 보조 |
| 고블린 엄폐조 | 엄폐 기습 / 돌팔매 견제 | 점착·노출·표식이 쌓일수록 기습 보너스 강화 |

## 적 의도와 취소 규칙

적 세 명은 라운드 시작에 표적과 피해 범위를 모두 공개한다. 적 의도도 적의 기본 속도와 의도 속도 보정으로 행동선에 섞인다. 단일 대상 표적은 생존 아군 중에서 고정하며, 실행 중 그 표적이 쓰러지면 그 적 행동은 `취소`다. 아군 기술의 표적 적이 앞 행동에서 쓰러져도 그 기술 역시 `취소`다. 숨은 자동 재표적은 없다.

## 기술적 경계와 안전성

```text
Domain.Combat
  Planning → Resolving → Planning / Victory / Defeat
  공유 SP, 속도 정렬 행동선, 확정 패키지, 보너스 확률, 상태, 취소

Application.Combat
  CombatTrainingSession
  난수 공급과 명령 경계

Presentation.Combat
  CombatTrainingCoordinator
  집행관 대화 완료, 입력 잠금, 행동선 자동 재생

  CombatTrainingView
  UGUI 투명 상단 헤더, 작은 부대 목록/인접 기술 패널, 전체 전투 배경, 곡선 화살표, 투명 하단 속도 행동선 렌더링
```

- 시작 훅은 `PrototypeInteractable.onInteracted`가 아니라 `DialogueFocusController.DialogueCompleted`이며 stable ID `combat-liaison-officer`로 필터한다.
- 전투 중 탐험 이동·대시·상호작용·카메라·대화 입력과 메뉴/지도 입력을 함께 잠근다.
- 종료·재시도·View 비활성화에서 자동 재생을 멈추고 입력 잠금을 정확히 반환한다.
- `Time.timeScale`은 바꾸지 않는다.
